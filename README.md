Raven is an operating system. It may be applied to a block of computing
hardware and then run applications.

## Orientation

Read the [operator's manual](./docs/operators-manual.md).

## Features

- Full software tracibility and reproducible from configuration.
- Secure data handling.
- Easy system backup and recovery.
- Experienced user in mind.
- Beautiful desktop environment.
- FOSS picks wherever possible; FOSS only by default.
- Strong media playing.
- It runs Crysis.

## System Requirements

The `harness` pattern consumes resources at rest from a fresh installation.

- Storage: Approximately 32Gb. You should bring a 64Gb drive or larger.
- Memory: 1.19 Gb. Your system should have at least 4Gb memory.
- Compute: 1% CPU usage. Measured on an Intel Core-8700.

## Unfree Software

No unfree-licensed software is enabled by default and all unfree software
is explicitly labeled. The onus is on the user to enable the unfree
software via simple edits to their copy.
