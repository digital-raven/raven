Firefox with a bunch of shit turned off.

If you really care about privacy in a web-browser then an
alternate librewolf is also provided.

Settings were determined by following [this guide](https://brainfucksec.github.io/firefox-hardening-guide)
and consideration of every entry in [Mozilla's policy templates](https://mozilla.github.io/policy-templates/).

## Extensions
These extensions are pre-installed.

1. UBlock Origin. Adblock is a basic safety requirement.
2. Unhook. Disable shorts on YouTube.
3. Return YT Dislike. Some vids blow.
4. ipvfoo. Show IP address of website.
5. Wayback Machine. Webpage archival.
6. Firefox Translations.

## Browser Behaviors
These were the motivating user considerations.

- Erase search and browsing history on close.
- Erase the session on close.
- Save logins locally.
- Preserve logins between browser crashes.
- Search is DuckDuckGo by default. Google toggleable.
- Geolocation via Mozilla instead of Google.
- Sponsored crap turned off. Disabled info gathering.

## Sync
Firefox can export bookmarks to html. Save this html encrypted
in `pass`. You should save your logins there too anyway.
